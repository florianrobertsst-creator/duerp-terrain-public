DUERP Terrain — application du téléphone (à publier une seule fois)
=====================================================================
Ce dossier contient uniquement le CODE de l'application : aucune donnée de client.
Les visites, textes et photos restent dans le téléphone jusqu'à l'envoi de la fiche.

Publication gratuite avec GitHub Pages
1. Créer un compte gratuit sur github.com, puis « New repository » (nom : duerp-terrain, public).
2. « uploading an existing file » : déposer tous les fichiers de CE dossier (index.html, app.js, styles.css,
   risques.js, sw.js, manifest.webmanifest, icone-192.png, icone-512.png).
3. Settings > Pages > Source : « Deploy from a branch », branche main, dossier /(root) > Save.
4. Après 1 à 2 minutes, l'adresse est : https://VOTRE-NOM.github.io/duerp-terrain/

Installation sur le Samsung
1. Ouvrir cette adresse dans Chrome, avec une connexion (une seule fois).
2. Menu ⋮ > « Ajouter à l'écran d'accueil » (ou « Installer l'application »).
3. Ouvrir DUERP Terrain une fois en ligne pour qu'il se mette en cache : il fonctionne ensuite sans connexion.

Dictée : touchez le micro du clavier (Samsung / Gboard) ; télécharger le français hors connexion dans
Réglages du clavier > Saisie vocale pour dicter sans réseau.

Circuit : DUERP Studio > Collecte terrain > « Exporter le contexte » > envoyer le fichier sur le téléphone
> l'importer dans DUERP Terrain (choix de l'UT) > sur le terrain : photos + dictée > « Envoyer à l'ordinateur »
> DUERP Studio > Collecte terrain > « Importer une collecte ».
